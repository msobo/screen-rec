# Changelog

All notable changes to ScreenRec are documented in this file.

## [0.3.0] – 2026-11-05

### Added
- English user interface, now the default, with German available under Settings → Language
- "About ScreenRec" window with version, license, and a link and QR code for support
- Info button in the recording window and the editor that opens the "About ScreenRec" window

### Fixed
- Minor fixes

## [0.2.0] – 2026-11-05

### Changed
- The recording window now opens right when the app starts
- The preview in the editor is larger and shows the image up to the edge

### Removed
- CRT effect in the preview

## [0.1.0] – 2026-11-05

### Added
- Record a screen or a single window, with system audio, microphone and camera
- Timeline editor: cut, trim, move, transitions and speed changes
- Auto zoom, smoothed cursor, backgrounds and keystroke overlays
- Export for YouTube, as original, ProRes or GIF
- Save projects and keep editing them later
